## Features

- *Ver Katanas**: Ver katanas registradas.

## Technologies Used

- **Java 17**
- **Spring Boot 3.2.2**
- **Maven**
- **Lombok**
- **GRPC 1.58.0**

## Prerequisites

- Java 17 or higher
- Maven 3.8 or higher
